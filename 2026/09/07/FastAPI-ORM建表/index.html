安装SQLAlchemy ORM和MySQL异步驱动

创建数据库引擎

定义模型类

  • class Base：基类（所有表都包含的字段）
    • 字段名: Mapped[python类型] = mapped_column(sqlalchemy类型,[default=默认值 or server_default=默认值],comment=注释)
    • Mapped[python类型]：特殊标记的类型注解，如果不加Mapped，该字段就不会被创建
    • default=默认值：Python 干活，把算好的值写进 INSERT 语句，函数不带小括号
    • server_default=默认值：数据库干活，把函数值写进表结构 DDL，函数带小括号
  • class Book：要创建的表
    • 通过 __tablename__ 指定要创建的表，后面再确定确定表字段

启动应用时建表

  • 创建时也可以写成Book.metadata.create_all，但是不规范
