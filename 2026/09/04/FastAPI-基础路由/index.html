FastAPI安装

构建简单路由

  • 通过 app = FastAPI() 创建实例
  • 通过 @app.请求方法(“请求路径”) 装饰器来定义路由
  • 通过装饰器下面的函数来定义响应规则，async 异步响应
  • uvicorn.run() 指定运行文件（main.py –> “main:app”）

请求方法

  • get：查
  • post：增
  • put：改
  • delete：删

路径参数/PATH注解

  • 注解
  • id : int 指定参数类型
  • Path: 注解
    • …：等同于Any，这里由客户端提供的任何值
    • gt：大于
    • ge：大于等于
    • lt：小于
    • le：小于等于
    • min_length：最小长度
    • max_length：最大长度
    • description：参数相关介绍

查询参数/Query注解

  • 注解
  • Query相关参数与Path一致

请求体参数/Field注解

  • Field相关参数与Path一致
